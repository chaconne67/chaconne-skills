# 인터뷰

2단계에서 채울 항목이다. 한 번에 하나씩, 추천 답과 이유를 붙여 묻는다. 0단계 조사나 사용자의 말로 이미 답이 나온 항목은 묻지 않고 "이렇게 이해했는데 맞나요?"로 확인만 받는다.

## 조사할 것과 물을 것

| 에이전트가 조사한다 | 사용자에게 묻는다 |
|---|---|
| 제품이 하는 일, 기능, 화면, 문구, 숫자 | 이 영상으로 무엇을 알리고 싶은가, 왜 지금인가 |
| 홈페이지·기획 문서·기존 카피에 이미 있는 메시지 | 그중 이 영상에서 꼭 남길 한 줄은 무엇인가 |
| 시청자가 겪는 문제와 쓰는 말(커뮤니티·후기·검색) | 누구에게 보여 주고 싶은가, 그 사람을 어떻게 아는가 |
| 같은 채널의 경쟁·유사 영상, 최근 유행, 카피 유형 | 좋아하는 영상·싫어하는 영상(링크), 원하는 느낌 |
| 게시처의 규격·길이 제한·권장 사항 | 어디에 올릴 것인가, 형식은 무엇인가 |
| 로고·색·글꼴·기존 화면 같은 자산 | 쓰면 안 되는 것(색·표현·말투·경쟁사 언급) |
| 음악의 저작권·Content ID 등록 여부 | 목소리·음악 취향, 내레이션을 넣을지 |
| — | 일정, 누가 승인하는지, 공개 범위 |

- 조사로 답이 나오지 않는 사실(예: 아직 정하지 않은 가격)은 사용자에게 묻되, "조사에서 찾지 못했다"고 함께 말한다.
- 사용자의 답이 조사 결과와 다르면 둘 다 보여 주고 어느 쪽을 따를지 묻는다. 에이전트가 하나를 골라 덮지 않는다.

## 항목과 순서

### 1. 형식 (가장 먼저)

형식이 화면비·길이·첫 장면·자막·안전 영역을 모두 정하므로 다른 항목보다 먼저 묻는다.

| 형식 | 화면비 | 길이 | 특징 |
|---|---|---|---|
| 숏폼(YouTube 쇼츠·릴스·틱톡) | 세로 9:16 | 15~60초 | 첫 1~2초에 멈춰 보게 할 장면이 필요. 소리 없이 보는 사람이 많아 자막을 화면에 넣는다. 플랫폼 단추·설명 글이 화면 가장자리를 가린다 |
| 일반 영상(유튜브·홈페이지·영업 자료) | 가로 16:9 | 1~3분 | 이야기 구조를 다 쓸 수 있다. 첫 5초에 무엇에 관한 영상인지 보인다 |
| 스토어 미리보기(MS Store·Google Play·App Store) | 스토어 규격 | 스토어 권장 | 처음 보는 사람이 "이게 뭐고 왜 필요한가"를 안다. 규격·길이는 게시 직전 각 스토어 도움말로 다시 확인한다 |
| 사용법 시리즈 | 가로 | 편마다 짧게 | 한 편에 기능 하나. 쉬운 것부터. 편마다 같은 틀 |
| 여러 형식 | — | — | 기준 형식 하나를 먼저 확정하고, 다른 형식은 같은 장면 목록에서 배치만 바꾼다 |

- 표의 길이는 출발점이다. 게시처의 실제 제한과 사용자의 기준이 앞선다.
- 형식이 둘 이상이면 무엇을 먼저 확정할지 묻는다.

### 2. 목적

- 이 영상을 본 사람이 무엇을 하길 바라는가(설치, 문의, 구매, 기능 사용, 기억).
- 무엇을 알리는 영상인가(제품 전체, 새 기능 하나, 회사).
- 성공을 어떻게 알 수 있는가(사용자가 기준이 없다고 하면 "미정").

### 3. 대상

- 누구인가(직업·상황·나이대), 이 제품을 이미 아는가.
- 이 사람이 지금 이 문제를 어떻게 해결하고 있는가(조사로 먼저 찾고 확인한다).
- 어디서, 어떤 상태로 보는가(출퇴근 중 휴대폰, 회의실 화면, 스토어 목록).

### 4. 메시지

- 영상이 끝나고 시청자에게 남을 한 줄.
- 피할 말·피할 주장(확인 안 된 숫자, 경쟁사 비교, 과장).

### 5. 취향

- 좋아하는 영상과 싫어하는 영상, 각각 무엇이 좋고 싫은지.
- 톤을 형용사 두 개로(예: "차분하다, 또렷하다"). 이 두 낱말이 이후 색·움직임·음악을 고르는 기준이 된다.
- 하지 않을 것(예: 3D, 반짝임, 어두운 바탕, 특정 색).

### 6. 소리

- 내레이션을 넣을지, 누가 말하는지(성별·나이대·말투, 1인칭 대표인지 해설자인지).
- 음악 분위기와 템포, 효과음을 쓸지.
- 사용자가 직접 만든 음악·목소리가 있는지.

### 7. 일정·승인·게시

- 언제까지, 누가 승인하는지, 어디에 누구 계정으로 올리는지.
- 검토본을 어디서 볼지(휴대폰이면 드라이브 등).

## 마무리

모든 항목을 기획 문서 「요구」 절에 표로 적고, 사용자가 "맞다"고 해야 3단계로 간다.
