## 핵심

AI에게 영상 전체를 한 번에 맡기지 않는다. 대본의 핵심을 이해시키고, 설명에 도움이 되는 지점만 골라 독립된 짧은 장면으로 만든다. 레퍼런스와 시각 규칙을 각 장면에 명확히 전달하고, 생성 결과를 편집자처럼 수정한다. 마지막 길이·리듬·음악·자막은 후반 편집에서 맞춘다.

이것은 존코바의 가감속·시간차·준비 동작 같은 움직임 원리를 대체하는 방법이 아니다. 그 원리를 적용할 장면을 코드·에이전트 기반으로 제작하고 조립하는 작업 방식이다.

## 1. 데이터 차트: 레퍼런스와 실제 데이터를 분리해 준비한다

출처 구간: [01:07](https://www.youtube.com/watch?v=y4YupFxhAog&t=67s), [01:26](https://www.youtube.com/watch?v=y4YupFxhAog&t=86s), [02:27](https://www.youtube.com/watch?v=y4YupFxhAog&t=147s).

### 설명에서 확인된 방법

1. Pinterest 등에서 원하는 차트 스타일의 참고 이미지를 모은다.
2. 차트에 사용할 데이터를 준비한다. 제작자는 Claude로 데이터를 찾는 예를 든다.
3. 참고 이미지와 데이터를 주고 HyperFrames용 애니메이션을 Claude Code로 제작한다.
4. 결과를 보고 대화로 배치·크기 등을 수정한다.

영상의 예시는 아프리카 인구 상위 10개 도시를 담은 7초짜리 9:16 막대그래프다. 도시 수·길이·화면비는 예제 조건이지 모든 작업의 기본값이 아니다.

### 스킬의 적용 원칙

레퍼런스 이미지는 디자인 근거이며 데이터의 사실 근거가 아니다. 실제 차트의 수치·단위·기준 시점·지역 정의·출처는 별도로 확인한다. 확인할 수 없는 수치를 보기 좋게 채워 넣지 않는다. 값에서 그래픽 길이·축 범위·라벨로 연결되는 관계를 유지하고 최종 출력에서도 확인한다.

## 2. 숏폼 안전 영역: 플랫폼 UI와 겹치지 않게 수정한다

출처 구간: [04:12](https://www.youtube.com/watch?v=y4YupFxhAog&t=252s).

### 설명에서 확인된 방법

처음 생성된 결과를 그대로 쓰지 않고, 숏폼의 안전 영역 안에 들어오도록 대화로 수정한다.

### 스킬의 적용 원칙

화면비만 맞는다고 납품 가능한 것은 아니다. 게시 플랫폼의 프로필·좋아요·공유 버튼·설명·자막이 화면 일부를 가릴 수 있다. 해당 플랫폼과 표시 크기에서 제목·핵심 수치·로고가 가려지는지 확인한다. 플랫폼을 확인하지 않은 고정 여백 수치를 보편 규칙으로 쓰지 않는다. 플랫폼 UI를 확인할 수 없으면 그 한계를 표시하고 중요한 내용은 가장자리에 붙이지 않은 시안을 만든다.

## 3. 대본에서 애니메이션이 필요한 부분을 고른다

출처 구간: [04:52](https://www.youtube.com/watch?v=y4YupFxhAog&t=292s), [05:39](https://www.youtube.com/watch?v=y4YupFxhAog&t=339s).

### 설명에서 확인된 방법

1. 레퍼런스 스타일·색·폰트를 전달한다.
2. 영상 대본을 전달하고 어느 지점에 애니메이션을 넣으면 좋을지 제안받는다.
3. 선택된 부분을 텍스트와 시각 요소가 결합된 짧은 설명 애니메이션으로 만든다.

### 스킬의 적용 원칙

모든 문장을 장식하지 말고, 관계·비교·변화·원인과 결과·조작 과정을 시각화했을 때 이해가 쉬워지는 곳을 선택한다. 말과 글만으로 충분한 구간은 그대로 유지한다. 장면표에는 대본 구간, 전달할 의미, 사용할 그래픽, 주요 동작, 필요한 데이터·에셋, 다음 장면과의 연결을 적는다.

## 4. 독립된 장면 지시서로 나누어 제작한다

출처 구간: [07:15](https://www.youtube.com/watch?v=y4YupFxhAog&t=435s).

### 설명에서 확인된 방법

장면마다 독립적으로 이해할 수 있는 프롬프트를 만들고 여러 Claude Code 대화에서 클립을 병렬 제작한다.

### 스킬의 적용 원칙

병렬 제작은 가능한 선택지이며 기본 의무가 아니다. 장면 간 상태·카메라·데이터가 이어지면 의존 관계를 먼저 정한다. 병렬로 나눌 때는 공통 스타일을 각 지시서에 전달하고 출력 위치·파일명을 분리한다. 다른 대화가 앞 대화의 결정을 안다고 가정하지 않는다.

장면 지시서에 필요한 정보:

- 장면의 목적과 대응하는 대본.
- 화면비·납품 해상도·클립 길이 또는 현재 편집상의 예상 길이.
- 참고 이미지 및 참고할 구체 속성.
- 색·폰트·그래픽 스타일·정확하게 유지할 문구와 로고.
- 시작·종료 상태, 시선의 중심, 주요 동작과 카메라 움직임.
- 필요한 데이터의 출처 및 허용된 에셋.
- 안전 영역, 편집 여유 구간, 출력 파일·편집 가능한 소스.
- 확인할 성공 조건과 아직 미확정인 조건.

이 목록은 이 스킬이 정리한 실무 전달 계약이다. 제작자가 공개한 프롬프트 원문을 복원한 것으로 표시하지 않는다.

## 5. 특정 질감·타이틀은 공식 디자인 자료로 구체화한다

출처 구간: [08:13](https://www.youtube.com/watch?v=y4YupFxhAog&t=493s), [10:12](https://www.youtube.com/watch?v=y4YupFxhAog&t=612s).

### 설명에서 확인된 방법

Apple의 Liquid Glass 디자인 문서를 참고시켜 팝업형 타이틀 보드를 만들고, 로고 같은 이미지를 추가한다.

### 스킬의 적용 원칙

‘고급스럽게’ 같은 형용사만 주기보다 질감·레이아웃의 참고 자료를 전달한다. 다만 유리 질감을 모든 프로젝트에 쓰지 않는다. 브랜드 톤·배경·텍스트 대비에 맞는 경우에 선택하고, 정확해야 할 로고는 승인된 원본 에셋으로 넣는다. 이 영상 설명만으로 Apple 디자인 지침의 세부 요건이나 효과 구현 코드를 확인했다고 하지 않는다.

## 6. 제작자가 정리한 여섯 가지 개선 요령

출처 구간: [10:50](https://www.youtube.com/watch?v=y4YupFxhAog&t=650s).

1. **참고 이미지를 준다.** 말로만 스타일을 요구하는 것보다 시각적 기준을 명확히 전달한다.
2. **전체 영상보다 개별 숏을 만든다.** 문제가 있는 부분만 다시 만들고 이어 붙일 수 있게 한다.
3. **카메라 움직임을 구체적으로 적는다.** Push in, Pan, Static처럼 이동과 고정 여부를 구분한다. 꼭 움직일 필요는 없다.
4. **편집자처럼 반복 수정한다.** 결과 전체를 무작정 재생성하기보다 무엇이 어디에서 맞지 않는지 짚는다.
5. **최종 타이밍·음악·자막은 후반 편집에 맡긴다.** 개별 클립 생성으로 완성 영상의 리듬까지 끝났다고 보지 않는다.
6. **시각 언어를 참고한다.** Vox, Apple, 패션, 기술 스타트업, 다큐멘터리 등의 구체적인 표현 방식을 레퍼런스로 삼는다. 특정 브랜드 이름만 주고 정확한 스타일이나 사용 권리가 확보됐다고 가정하지 않는다.

## 기존 제작 절차와 통합하는 법

기획·스타일 확정 → 대본의 시각화 지점 선택 → 장면표와 거친 시간 시안 → 장면별 지시서 → 사용 가능한 도구로 클립 제작 → 내용·수치·안전 영역 수정 → 최종 편집·음악·자막 → 실제 재생 검수.

초기 애니메틱에서 전체 흐름과 예상 박자를 설계하는 것과, 최종 타이밍을 후반 편집에서 맞추는 것은 서로 다른 단계다. 생성된 클립 때문에 읽기 시간이나 음악의 박자를 억지로 바꾸지 않도록 앞뒤 편집 여유를 확보하고, 최종 편집에서 전환과 정보 구간을 구분한다.

## 비용·성과·도구 선택에 관한 경계

- 제작자의 ‘바이럴’, ‘조회수 성과’, 특정 모델이 더 좋다는 설명은 제작자 주장이지 이번 조사에서 재현한 성과가 아니다. 제작의 성공 조건으로 쓰지 않는다.
- HyperFrames를 영상에서 무료 도구로 소개하지만 현재 요금·관련 서비스 비용이 모두 무료라고 보장하지 않는다.
- Claude Code를 설명하지만 특정 모델을 스킬 기본값으로 고정하지 않는다. 기존 도구와 승인된 인증·비용 범위를 따른다.
- Typeless 소개는 후원 구간이다. 이 제작 방식의 필수 도구나 의존성으로 넣지 않는다.
- 이 문서는 방법 참조 자료다. HyperFrames를 설치하거나 기존 렌더 경로를 교체한 상태가 아니다.
